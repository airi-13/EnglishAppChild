# テスト結果（Cloudflare版）

実施日: 2026-10-23 / 環境: Node 22（D1の代役に node:sqlite）、Chromium（Playwright）

| 種類 | 内容 | 結果 |
|---|---|---|
| 自動テスト | 42件（認証・初期設定・出題の全経路・同時送信・AI障害・集計・CSV・Gemini通信・AI接続チェック・40人同時利用） | 全件合格 |
| ブラウザ操作 | 初期設定から、サンプル1,600問の取り込み、生徒の全フロー、管理者の集計・CSV書き出しまで（31項目） | 全項目合格、ブラウザのエラー0件 |

## 主に確認した内容
- **同時送信**: 同じセットを同時に2回送ると、片方だけが成功し、もう片方は409。記録は重複しない。
- **同時開始**: 同じ生徒が同時に3回「問題を出す」を押しても、進行中のセットは1つ。
- **AI障害**: 全面停止でも、本文→空欄→解説→確認テスト→完了まで進める。復旧後は通常採点に戻る。
- **AIへの送信内容**: 生徒のID・表示名・パスワード・APIキーを含まない。回答中の命令は「データ」として渡される。
- **初期設定**: トークン未設定は不可／違うトークンは拒否／5回間違えるとロック／管理者が作成済みなら409。
- **分割して取り込むCSV**: 確認だけ（dry_run）で全体を検証し、不備があれば1問も書き込まない。分割をまたぐ重複も検出。
- **1回のAPI呼び出しのD1クエリ数**: 最大40以下（無料枠の上限は、1リクエストあたり1,000）。

## 確認できていないこと（正直な注意）
1. **実際のCloudflare（Workers・D1）での動作**: この環境ではCloudflareに接続できず、D1の代役（SQLite）と、Workersと同じWeb標準のAPI（Node上）で確認しました。実際のCPU時間、D1の挙動の細かい差は、公開後に確認が必要です。
2. **本物のGeminiとの通信**: Gemini互換のテスト用サーバーでの確認です。公開後に、管理画面の「AI接続チェック」で確認してください。
3. **Cloudflareのダッシュボードの操作画面**: 手順書は、公式ドキュメントの確認と、一般的な画面の名前に基づきます。名前が違う場合は、近い項目を探してください。
